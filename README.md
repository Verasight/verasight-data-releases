# Verasight Data Releases

This repository indexes public Verasight report repositories and data-release materials.

It is the map across the report library. Individual `verasight-report-*` repositories hold report-specific methodology, questionnaire text, toplines, codebooks, citation metadata, and reuse terms. The Verasight Data Library remains the curated public data-room surface, while report repositories provide structured files for researchers, journalists, search engines, and LLMs.

## Status Definitions

- `ready_for_draft`: canonical Data Library outputs and methods files exist locally.
- `needs_canonical_reconciliation`: canonical wave summary counts and canonical question files disagree; hold publication until the Data Library bookkeeping is repaired.
- `blocked_raw_present`: raw files exist locally, but a methods/package blocker prevents publication.
- `sheet_only_missing_data`: the source sheet has a public report row, but no data ZIP is listed.
- `upcoming`: the source sheet marks the report as upcoming.
- `needs_mapping`: an existing public repo scaffold exists, but the matching raw/canonical source needs confirmation.

Unless a specific report repository says otherwise, indexed materials are provided for reference only. Contact Verasight for reuse, redistribution, adaptation, or commercialization.
